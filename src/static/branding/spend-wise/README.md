# Spend Wise logo concepts

Open index.html or /static/branding/spend-wise/index.html through Flask.

1. Considered Wallet: wallet with an integrated checkmark (recommended).
2. Budget Map: budget compartments with a checked expense.
3. Receipt Trail: a receipt with expense lines and a tracking dot.

Each concept has icon and full-logo SVGs in light, dark, mono, and mono-white variants. All backgrounds are transparent. Light/dark names describe the intended background. Full logos use editable Arial / Helvetica / sans-serif text; the symbol is original vector geometry. Use the icon SVG as the favicon after selection. Mockups are illustrative and do not submit forms. Existing production branding is unchanged.
